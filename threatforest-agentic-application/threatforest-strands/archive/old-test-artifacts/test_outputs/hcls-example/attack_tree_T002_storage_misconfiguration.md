# Attack Tree: Storage Misconfiguration

**Threat ID**: T002  
**Associated threat statement**: An external attacker with basic reconnaissance capabilities, can exploit misconfigured S3 bucket permissions, which leads to raw healthcare data exposure to unauthorized users or public access, resulting in reduced confidentiality of PHI/PII Data and Research Data.

- **Threat Source**: External attacker
- **Prerequisites**: Basic reconnaissance capabilities
- **Threat Action**: Exploit misconfigured S3 bucket permissions
- **Threat Impact**: Raw healthcare data exposure to unauthorized users or public access
- **Reduced Goal**: Confidentiality
- **Impacted Assets**: PHI/PII Data, Research Data
- **Priority**: High
- **Category**: Storage Misconfiguration
