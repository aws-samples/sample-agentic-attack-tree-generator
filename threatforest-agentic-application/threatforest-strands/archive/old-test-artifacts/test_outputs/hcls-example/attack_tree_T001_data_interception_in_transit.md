# Attack Tree: Data Interception in Transit

**Threat ID**: T001  
**Associated threat statement**: A network attacker with position on communication paths, can intercept healthcare data during transmission from SaaS applications to AWS AppFlow, which leads to PHI exposure, resulting in reduced confidentiality of PHI/PII Data.

- **Threat Impact**: PHI exposure
- **Reduced Goal**: Confidentiality
- **Impacted Assets**: PHI/PII Data
- **Priority**: High
- **Category**: Data Interception in Transit
