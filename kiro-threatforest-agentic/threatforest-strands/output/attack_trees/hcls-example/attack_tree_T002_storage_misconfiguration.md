# Attack Tree: Storage Misconfiguration

**Threat ID**: T002  
**Associated threat statement**: A malicious actor with internet access, can exploit misconfigured S3 bucket permissions, which leads to exposure of raw healthcare data to unauthorized users or public access, resulting in reduced confidentiality of PHI/PII Data.

- **Threat Source**: Malicious actor
- **Prerequisites**: Internet access
- **Threat Action**: Exploit misconfigured S3 bucket permissions
- **Threat Impact**: Exposure of raw healthcare data to unauthorized users or public access
- **Reduced Goal**: Confidentiality
- **Impacted Assets**: PHI/PII Data
- **Priority**: High
- **Category**: Storage Misconfiguration
