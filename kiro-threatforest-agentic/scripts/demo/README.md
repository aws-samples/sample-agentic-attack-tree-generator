# Demo Scripts

Demonstration scripts showcasing ThreatForest features and capabilities.

## Scripts

### `demo_cli_features.py`
Demonstrates the enhanced CLI features and user experience improvements.

**Features:**
- Shows comprehensive help system
- Demonstrates logging configuration
- Showcases error handling improvements
- Illustrates command examples

**Usage:**
```bash
python scripts/demo/demo_cli_features.py
```

### `demo_setup_wizard.py`
Demonstrates the interactive setup wizard functionality.

**Features:**
- Shows guided configuration process
- Demonstrates AWS credential detection
- Illustrates model selection and recommendations
- Shows configuration validation

**Usage:**
```bash
python scripts/demo/demo_setup_wizard.py
```

### `demo_validation.py`
Demonstrates the configuration validation and diagnostic features.

**Features:**
- Shows configuration validation process
- Demonstrates system health checks
- Illustrates troubleshooting workflows
- Shows diagnostic capabilities

**Usage:**
```bash
python scripts/demo/demo_validation.py
```

## Requirements

- ThreatForest installed in development mode
- AWS credentials configured (for some demos)
- Interactive terminal for best experience
