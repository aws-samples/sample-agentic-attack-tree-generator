    Attack Tree: Authorization

    Threat ID: c5ac485c-a985-4004-be21-1fb26173a2d3 Statement: A threat actor with access to modify network traffic can manipulate API parameter input which leads to the API Gateway performing actions on another user's resources, resulting in reduced integrity and confidentiality of vehicle registration, vehicle listing, registration status, and vehicle registration documents.
