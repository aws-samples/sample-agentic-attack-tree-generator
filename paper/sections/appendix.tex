\section{Phase Detection Keywords}
\label{app:phases}

The automated phase coverage metric matches attack tree node descriptions against keyword lists for 12 MITRE ATT\&CK tactics. The dictionary contains 130+ terms. Representative examples:

\begin{itemize}
    \item \textbf{Initial Access}: phishing, exploit public, drive-by, supply chain, valid accounts
    \item \textbf{Privilege Escalation}: escalate, elevate, admin, root, UAC bypass, token
    \item \textbf{Lateral Movement}: pivot, spread, pass the hash, RDP, SSH, remote service
    \item \textbf{Exfiltration}: exfiltrate, transfer, upload, data theft, steal data
\end{itemize}
